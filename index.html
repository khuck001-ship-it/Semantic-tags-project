Semantic HTML Tags

This website explains the semantic HTML tags.

Header Article Footer

Header Tag

The header tag is used for the title or introduction of a page.

Article Tag

The article tag holds content that can stand on its own, like a blog post.

Extra Fact: Semantic tags make web pages easier to read and understand.

What does the Details tag do?

The details tag hides information until the user clicks to open it.

The footer contains information about the website such as copywrite/authors.
